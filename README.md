# Python Internship – Task 1: Calculator

A simple calculator built with Python for the SAM AI Technologies internship.

## Features
- Addition, subtraction, multiplication and division
- Supports decimal numbers
- Handles division by zero, invalid numbers and invalid operations

## How to Run
Install Python, open CMD in the project folder, and run:

```cmd
python calculator.py
```

Enter two numbers and choose an operation: +, -, * or /.

## Example
First number: 10
Second number: 5
Operation: +
Result: 15.0
